## 미검증 항목 (이 환경에서 실행 불가)

| 항목 | 이유 | 다음 단계 |
|---|---|---|
| 실제 Android/iOS 기기에서의 터치·성능 | 실기기·SDK 없음 | 오너 PC 에 Godot + Android 내보내기 템플릿 설치 후 APK 테스트 |
| 노치/안전 영역 실제 배치 | 모바일 OS 필요 | `SafeArea` 코드 구현 완료, 실기기 확인 필요 |
| 사운드 | 에셋 없음, 장치 없음 | 2단계에서 BGM/효과음 추가 |
| 에디터(GUI)에서 열기 | 화면 없는 환경 | 헤드리스 에디터 임포트는 성공. 오너 PC 에서 확인 요망 |

## 발견하고 수정한 버그 (개발 중)

1. 출구 이동 시 페이드 아웃 동안 이전 맵 플레이어가 위치를 덮어써 새 맵의 엉뚱한 곳(벽 밖)에 등장 → 전환 중 입력 잠금으로 해결.
2. 대사와 "아이템 획득" 안내 사이 1프레임 동안 이동 잠금이 풀림 → 대화 실행 전체 구간 잠금.
3. 전투/매복 트리거가 장면 시작 0.4초 동안 무시돼 빨리 걸어가면 매복이 발동하지 않음 → "영역 안에서 시작한 경우만 벗어날 때까지 무시"로 변경.
4. 전투 승리 레벨업 후 전투 화면 HP/MP 표시가 이전 값 → 레벨업 시 동기화.
5. 터치 버튼이 대화창 뒤로 비침 → 대화·메뉴 중 숨김.
6. 설정 창이 타이틀 글자와 겹침, 무술 메뉴 「뒤로」 버튼 잘림, 수련장 모래 위 풀밭 타일 → 수정.
